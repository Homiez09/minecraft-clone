# VoxelCraft

เกม 3 มิติแนว Minecraft ที่เล่นในเบราว์เซอร์ สร้างด้วย Three.js — โลกไม่มีที่สิ้นสุด ทุบและวางบล็อกได้
มีวงจรกลางวัน–กลางคืน และบันทึกความคืบหน้าไว้เล่นต่อได้

ทั้งเกมไม่มีไฟล์ภาพหรือไฟล์เสียงเลยแม้แต่ไฟล์เดียว — ลาย texture ทุกลายวาดด้วย Canvas API
และเสียงทุกเสียงสังเคราะห์สดด้วย Web Audio API ตอนเกมเริ่มทำงาน

## วิธีเล่น

```bash
npm install
npm run dev
```

แล้วเปิด <http://localhost:5173> ในเบราว์เซอร์

สร้างไฟล์สำหรับนำไปวางบนเว็บจริง:

```bash
npm run build     # ผลลัพธ์อยู่ในโฟลเดอร์ dist/
npm run preview   # ลองเล่นเวอร์ชันที่ build แล้ว
npm test          # ตรวจระบบสร้างโลกและ mesher (ไม่ต้องเปิดเบราว์เซอร์)
```

## สิ่งที่มีในเกม

**โลกไม่มีที่สิ้นสุด** — ภูมิประเทศสร้างจาก simplex noise แบบ deterministic เดินไปทางไหนโลกก็สร้างต่อไปเรื่อยๆ
seed เดียวกันได้โลกเดียวกันเป๊ะเสมอ มี 9 ชีวนิเวศ (ทุ่งหญ้า ป่า ทะเลทราย ภูเขา ทุ่งหิมะ ยอดเขาหิมะ สะวันนา ชายหาด มหาสมุทร)
พร้อมถ้ำใต้ดินแบบอุโมงค์คดเคี้ยว สายแร่ 4 ชนิดที่ฝังลึกต่างระดับกัน ต้นไม้ 3 ชนิด และทะเลที่ระดับน้ำ y=48

**บล็อก 42 ชนิด** ตั้งแต่หญ้า หิน ไม้ ทราย ไปจนถึงกระจก น้ำแข็ง หินเรืองแสง และขนแกะ 10 สี

**บรรยากาศ** — วงจรกลางวัน–กลางคืนยาว 10 นาทีจริง ท้องฟ้าไล่สีตามมุมดวงอาทิตย์
มีดวงอาทิตย์ ดวงจันทร์ ดาว เมฆก้อนเหลี่ยมที่ลอยตามลม ผิวน้ำเป็นระลอกคลื่น และมุมมองใต้น้ำ

**บันทึกเกม** — เก็บลง IndexedDB โดยบันทึกเฉพาะบล็อกที่ผู้เล่นแก้ไข ไม่ใช่ทั้งโลก
ไฟล์เซฟจึงเล็กมากแม้เดินสำรวจไปไกลแค่ไหน บันทึกอัตโนมัติทุก 30 วินาที และตอนกด `Esc`

## โครงสร้างโค้ด

```
src/
├── main.js              ตัวประสานทั้งหมด + ลูปหลักของเกม
├── config.js            ค่าคงที่ทุกตัวรวมไว้ที่เดียว
├── blocks.js            นิยามบล็อกและตารางค้นหาแบบ typed array
├── textures.js          วาด texture atlas ด้วย Canvas ตอนเริ่มเกม
├── world/
│   ├── terrain.js       noise → ภูมิประเทศ ชีวนิเวศ ถ้ำ แร่ ต้นไม้
│   ├── mesher.js        voxel → geometry (face culling + ambient occlusion)
│   ├── Chunk.js         ที่เก็บ voxel ของ chunk เดียว
│   ├── World.js         โลกทั้งหมด + อ่าน/เขียนบล็อก + ส่วนต่างสำหรับเซฟ
│   ├── ChunkManager.js  สตรีมโลก, worker pool, จัดการ mesh ใน scene
│   └── rng.js           ตัวสุ่มแบบกำหนดค่าได้
├── workers/chunkWorker.js  สร้างภูมิประเทศและ geometry นอก main thread
├── player/              ฟิสิกส์ อินพุต และการเล็งบล็อกแบบ voxel raycast
├── render/              ท้องฟ้า เมฆ material ของบล็อก
├── ui/                  แถบไอเทม แผงดีบัก เมนู
├── audio/sfx.js         เสียงสังเคราะห์
└── save/storage.js      IndexedDB
```

## หมายเหตุด้านเทคนิค

**การสตรีม chunk** — chunk ขนาด 16×128×16 เก็บเป็น `Uint8Array` แบน งานหนักสองอย่าง
(สร้างภูมิประเทศ และแปลง voxel เป็น geometry) ทำใน Web Worker 4 ตัว แล้วส่งผลลัพธ์กลับแบบ
transferable ให้ main thread ประกอบเป็น `BufferGeometry` ได้ทันทีโดยไม่ต้องคัดลอกซ้ำ
การอัปโหลดเข้า scene ถูกจำกัดไว้ 2 chunk ต่อเฟรมเพื่อไม่ให้เฟรมกระตุก

chunk จะถูกสร้าง mesh ก็ต่อเมื่อเพื่อนบ้านทั้ง 8 ทิศมีข้อมูลครบแล้ว เพราะการตัดหน้าที่มองไม่เห็น
และการคำนวณ ambient occlusion ต้องอ่านบล็อกที่อยู่ข้าง chunk ระบบจึงสร้างข้อมูลเผื่อไว้
1 วงแหวนรอบระยะมองเห็นเสมอ

**แสงเงา** — คำนวณครั้งเดียวตอนสร้าง mesh แล้วอบลงใน vertex color ประกอบด้วย ambient occlusion
จากบล็อกรอบมุม ความสว่างตามทิศของหน้า และความมืดตามความลึกใต้ผิวดิน (คำนวณจาก heightMap
ซึ่งต่อเนื่องข้าม chunk จึงไม่เกิดเส้นรอยต่อ) ทำให้ตอนเรนเดอร์ไม่ต้องพึ่ง dynamic light เลย

**texture atlas** — แต่ละ tile วาดที่ 16×16 px แล้ววางลง atlas พร้อมขอบกันชน 8 px
ที่เป็นภาพเดิมซ้ำต่อเนื่อง เพื่อไม่ให้สีของ tile ข้างเคียงรั่วเข้ามาเมื่อ mipmap ย่อภาพลง

**การชน** — AABB ขนาด 0.6 × 1.8 × 0.6 แก้การชนทีละแกน และซอยการเคลื่อนที่เป็นก้าวย่อย
เมื่อเฟรมตก เพื่อไม่ให้พุ่งทะลุกำแพง มีการปีนขึ้นบล็อกเดียวอัตโนมัติเวลาเดินชนขอบเตี้ยๆ
